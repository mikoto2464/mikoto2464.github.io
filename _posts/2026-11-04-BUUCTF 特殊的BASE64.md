查看文件类型
```
> file 1.exe
1.exe: PE32+ executable for MS Windows 5.02 (console), x86-64, 18 sections
```

IDA打开后能够在左侧找到main函数，F5就可以看到伪代码，很显然下图中是密文
![](https://img.h1kari.cn/blog/images/714ff60a880ac7e79bb2617d141e128dab0172c3ed7f59222de41301b738fd95.webp)

进入`base64Encode`函数，不难观察到这是标准的`base64`算法，且注意到此处重复出现`baseKey`
![](https://img.h1kari.cn/blog/images/41fdcfccebb9bb56b65456db563b20a94366e349bdb51f12e151a65ee0a04482.webp)

查看`baseKey`即`_ZL7baseKey`的引用
![](https://img.h1kari.cn/blog/images/18c3b3cf1e594cf5658b5e439c0e41d14365bfcaf6a3d4eaadee6de9e6f39d9c.webp)
