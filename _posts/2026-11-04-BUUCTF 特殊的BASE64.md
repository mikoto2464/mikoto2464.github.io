查看文件类型
```
> file 1.exe
1.exe: PE32+ executable for MS Windows 5.02 (console), x86-64, 18 sections
```

IDA打开后能够在左侧找到main函数，F5就可以看到伪代码，很显然下图中是密文
![](https://img.h1kari.cn/blog/images/a208bb25e62db1abf2680706f5c2c3d636379f4f3878fe43420648f76c8db428.png)

进入`base64Encode`函数，不难观察到这是标准的`base64`算法，且注意到此处重复出现`baseKey`
![](https://img.h1kari.cn/blog/images/ac6c0ae48d0a83020438850d00ea81f2770c41a167bd44a205bc58f06865c41c.png)

查看`baseKey`即`_ZL7baseKey`的引用
![](https://img.h1kari.cn/blog/images/2f8d397d532665eecb4e9b4a11235960970147dc1b3f25c9b04773da4524425b.png)

可以找到`__static_initialization_and_destruction_0`函数
![](https://img.h1kari.cn/blog/images/31e4fee452493b72e97578472e3b9b12bee0fc35bc9eb7f7740f87063035a2ce.png)

根据自定义的base64字符表即可解密得到flag`flag{Special_Base64_By_Lich}`
![](https://img.h1kari.cn/blog/images/36eeb99cb2a8d943bb77a9ae98398e97f22b72b80cfad8bc9c96751c2046efc7.png)
